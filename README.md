# Fithuner

A cross-platform file explorer focused on UI and UX, built with Tauri, React and TypeScript.

## Highlights
- Configurable file preview (images, text/code, PDF, audio, video, Markdown, JSON, CSV, folders)
- Settings screen to enable, disable or tune features
- Automatic updates
